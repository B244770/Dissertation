# Strategies to improve adaptation in plant breeding with complex genotype by environment interactions

Welcome to the **Strategies to improve adaptation in plant breeding with complex genotype by environment interactions** repository! This project focuses on data generation, surrogate model training, and optimisation algorithms. Below you will find an overview of the contents of this repository.

## Repository Structure

### `main/`
This is the primary directory containing the core elements of the project:

- **Data Generation:** Scripts for generating the data required for model training and testing.
- **Models:** Code for defining, training, and evaluating machine learning models.
- **Optimisation Algorithms:** Implementation of optimization techniques used to fine-tune the models.
- **Generated Data:** Output data produced by the data generation scripts.
- **Results and Visualisations:** Graphs, charts, and other visual representations of the model's performance and results.

### `main_history_version/`
This directory contains the historical versions of the code. Each version is named according to its function and the date it was created, following the pattern `function_MMDD` or `MMDD_function`. This allows for easy tracking of changes and evolution in the codebase.

- **Version Naming Convention:** Files in this directory follow the `function_MMDD` or `MMDD_function` format, where `function` describes the main purpose of the code, and `MMDD` indicates the date of the version.

## Code Documentation

The code across all scripts and modules is thoroughly commented, providing explanations of the logic and functionality.
